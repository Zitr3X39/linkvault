# Telegram-бот для MONOLITH — настройка за 3 минуты

Что это даёт: пересылаешь боту любое сообщение со ссылками — и в течение 15 минут они сами появляются на сайте. Комп включать не нужно: всё делает GitHub Actions.

## Шаг 1. Создай бота (1 минута)

1. В Telegram открой **@BotFather** (официальный, с галочкой).
2. Напиши ему `/newbot`.
3. Придумай имя (например, `MONOLITH Saver`) и юзернейм на конце `bot` (например, `monolith_zitr3x_bot`).
4. BotFather ответит токеном вида `7123456789:AAH...` — скопируй его.

## Шаг 2. Положи токен в секреты репозитория (1 минута)

1. Открой `github.com/Zitr3X39/linkvault` → **Settings** → **Secrets and variables** → **Actions**.
2. **New repository secret**.
3. Name: `TELEGRAM_BOT_TOKEN`. Secret: вставь токен. **Add secret**.

## Шаг 3. Разбуди бота (10 секунд)

1. Открой своего бота в Telegram и нажми **Start** (или напиши `/start`). Без этого бот не увидит твои сообщения.
2. Перешли ему любое сообщение со ссылкой.

## Проверка

В репозитории: **Actions** → **Telegram sync** → **Run workflow**. Через полминуты ссылка должна закоммититься в `data/links.json`, а сайт обновится сам.

Дальше всё автоматически: Action запускается каждые 15 минут. Бесплатно, лимитов для твоего объёма хватит с запасом.

## Если захочешь удалить бота

У @BotFather: `/mybots` → выбрать бота → **Delete bot**. И удали секрет в Settings → Secrets.
