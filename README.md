# LinkVault — твоё хранилище ссылок как сайт

Один сайт, где лежит всё: репозитории, каналы, тулзы, видео.
По категориям, каждая — свой цвет. Ссылка + название + короткое описание, что это такое.
Никаких API-ключей не нужно.

---

## 1. Как выложить сайт (один раз, 6 шагов)

1. Поставь Git: https://git-scm.com/download/win — всё по умолчанию, просто «Next».
2. На github.com создай пустой репозиторий с именем `linkvault`, видимость **Public**.
   Галочки «Add a README» и прочее ставить НЕ надо.
3. Распакуй эту папку куда-нибудь вроде `C:\LinkVault`.
4. Запусти **PUBLISH.bat** → он спросит ссылку на репозиторий.
   Вставь вида `https://github.com/ТВОЙ_ЛОГИН/linkvault.git` и нажми Enter.
   Гит один раз попросит войти в GitHub — жми «Sign in with your browser».
5. На GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
6. Через 1–2 минуты сайт живёт:
   `https://ТВОЙ_ЛОГИН.github.io/linkvault/`

Добавь адрес в закладки или закрепи вкладку (ПКМ по вкладке → «Закрепить»).
Открывается с любого устройства — телефон, второй комп, что угодно.

## 2. Три способа добавлять ссылки

**А. Прямо на сайте.** Кнопка «Добавить» → вставь хоть одну ссылку, хоть портянку текста.
Ссылки выдернет само, дубли отсечёт, категорию поставит само.

**Б. Автосбор из Telegram** — пункт 3.

**В. Файлы и закладки (TikTok, браузер)** — пункт 5.

---

## 3. Автосбор из Telegram

1. Поставь Python: https://python.org/downloads — при установке галочка **Add python.exe to PATH**.
2. В командной строке: `pip install telethon`
3. https://my.telegram.org → API development tools → создай приложение.
   Нужны два значения: **api_id** и **api_hash**.
4. Открой `sync\config.json` блокнотом и впиши их:

```json
{
 "api_id": 1234567,
 "api_hash": "сюда хэш",
 "chats": ["me", "имя_канала", -1001234567890],
 "limit": 3000,
 "enrich": true
}
```

`"me"` — это твоё «Избранное» (Saved Messages), где обычно всё и копится.
Добавляй любые каналы и чаты — по юзернейму или по ID.

5. Запусти **SYNC_TELEGRAM.bat**. Первый раз спросит номер телефона и код из Telegram, дальше вход не нужен.
6. Согласись на публикацию в конце — или потом запусти PUBLISH.bat вручную.

Скрипт запоминает, где остановился (`sync\state.json`), и в следующий раз берёт только новые сообщения.

## 4. Чтобы собиралось само каждый день

Пуск → «Планировщик заданий» → **Создать простую задачу**:

- Имя: `LinkVault`
- Триггер: ежедневно, например в 21:00
- Действие: «Запуск программы» → `C:\LinkVault\SYNC_TELEGRAM.bat`, аргумент `/auto`

Аргумент `/auto` убирает вопросы и сразу публикует изменения на сайт.

## 5. TikTok, закладки браузера и прочие файлы

Кинь файлы мышкой прямо на **IMPORT.bat** — или положи их в папку `inbox\` и запусти его.

| Формат | Откуда взять |
|---|---|
| `.html` | Chrome: `chrome://bookmarks` → ⋮ → Экспорт закладок |
| `.txt`, `.md`, `.csv` | Любой текст со ссылками, хоть скопированная переписка |
| `.json` | TikTok: Настройки → Настройки конфиденциальности → Скачать данные |

После импорта — PUBLISH.bat.

## 6. Как пользоваться сайтом

- Слева — категории с цветами и счётчиками, ниже — фильтр по источнику (GitHub / Telegram / TikTok…).
- Поиск ищет по названию, описанию, заметке, тегам и адресу.
- Звёздочка на карточке — в избранное, карандаш — правка названия, описания, категории, тегов и заметки.
- Фильтры попадают в адрес страницы — можно сохранить закладкой конкретную категорию:
  `…/linkvault/?cat=vibecoding`
- Горячие клавиши: `/` — в поиск, `Esc` — закрыть окно.
- Луна в шапке — светлая/тёмная тема.

## 7. Правки прямо в браузере: два режима

**Режим А — без токена (по умолчанию).**
Всё, что правишь на сайте, хранится в этом браузере. Слева внизу кнопка
«Скачать links.json» — скачай, положи файл в папку `data\`, запусти PUBLISH.bat.

**Режим Б — с токеном (удобнее).**
Правки сразу улетают в репозиторий и видны на всех устройствах:

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
2. Repository access: **Only select repositories** → твой `linkvault`
3. Permissions → Repository permissions → **Contents: Read and write**
4. Скопируй токен → на сайте шестерёнка → вставь в поле и сохрани

Токен лежит только у тебя в браузере. Кнопка «Забыть токен» стирает его.

> Если репозиторий Public — список ссылок виден всем, кто знает адрес.
> Не клади туда приватные ссылки-приглашения и доступы.

## 8. Что где лежит

```
index.html            сам сайт
assets/styles.css     оформление
assets/app.js         логика интерфейса
data/links.json       все твои ссылки (единственный важный файл — бэкапь его)
data/categories.json  категории, цвета и правила автораскладки
sync/tg_sync.py       сбор из Telegram
sync/import_files.py  импорт из файлов
sync/vaultlib.py      общая логика разбора ссылок
sync/config.json      ключи Telegram и список чатов
SYNC_TELEGRAM.bat     собрать из Telegram
IMPORT.bat            импорт файлов (можно перетаскивать мышкой)
PUBLISH.bat           выложить изменения на сайт
PREVIEW.bat           посмотреть локально до публикации
```

Свои категории или цвета — правь `data/categories.json`: там же списки доменов и слов,
по которым ссылка автоматически попадает в нужную категорию.

## 9. Если что-то не так

| Симптом | Что делать |
|---|---|
| Сайт открывается, но пустой | Подожди минуту после публикации и обнови страницу через Ctrl+F5 |
| 404 на адресе Pages | Settings → Pages: ветка `main`, папка `/ (root)` |
| PUBLISH.bat: «git не найден» | Поставь Git с git-scm.com и перезапусти |
| SYNC: «нет telethon» | В командной строке: `pip install telethon` |
| Названия ссылок кривые | Не все сайты отдают описание — поправь карандашом на карточке |
| Правки в браузере пропали | Это режим А и была очистка данных сайта. Ставь токен (режим Б) |
